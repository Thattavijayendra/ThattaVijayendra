## 01 · Telangana EV Analytics

### From government open data to an analytical dashboard.

I explored EV charging electricity-consumption data across Telangana, working with public datasets covering **January 2023 to August 2026**.

What makes this project different from a typical dashboard project is the work before the dashboard — data collection, scraping, cleaning, validation, anomaly checks, and exploratory analysis.

**What I worked on**

- Collected data from the Telangana Open Data Portal
- Automated data collection using Playwright
- Standardized datasets from different sources
- Checked missing values and duplicate records
- Investigated negative and inconsistent readings
- Performed EDA and statistical analysis
- Compared consumption across regions
- Built a three-page Power BI dashboard
- Used DAX for dashboard calculations

**Tools**

`Python` `Pandas` `NumPy` `Playwright` `Power BI` `DAX`
